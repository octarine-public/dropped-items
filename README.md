# Dropped items
- [x] Draws every item lying in the world where it lies
- [x] Item level, charges and cooldown on the icon
- [x] Icon size and corner rounding are set in the menu
- [x] Nothing is drawn over the shop, the minimap or the scoreboard
---
# Выпавшие предметы
- [x] Отрисовка каждого лежащего в мире предмета на его месте
- [x] Уровень, заряды и перезарядка предмета на иконке
- [x] Размер иконки и скругление углов настраиваются в меню
- [x] Ничего не рисуется поверх магазина, миникарты и таблицы счёта
---
# 掉落物品
- [x] 在掉落物品的所在位置绘制它们
- [x] 图标上显示物品等级、充能和冷却
- [x] 图标大小与圆角可在菜单中设置
- [x] 不会绘制在商店、小地图和记分板上方
